# Riya-Desk repository

This repository is the riyadesk.com website: a static site served by GitHub Pages from `main`, with no build step. The `CNAME` file points it at riyadesk.com.

`lead-portal-demo/` is a separate clickable sales demo with its own instructions in `lead-portal-demo/CLAUDE.md`. Read that file before changing anything in the folder, and keep demo work inside it. Don't change the portfolio pages (`index.html`, `about/`, `case-studies/`, `concepts/`, `strategy/`, `media/`) unless the user asks.

Project skills for the demo: `/portal-debug`, `/portal-change-numbers`, `/portal-add-screen`, `/portal-ship`.
